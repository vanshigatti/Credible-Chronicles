## Problem Statement
Misinformation spreads rapidly in India through social media platforms such as WhatsApp, Facebook, and Telegram. Most existing fact-checking systems mainly focus on English content, leaving regional language news largely unchecked. This creates a major gap in detecting fake news for millions of users who consume content in Indian languages, leading to confusion, panic, and the spread of unverified information.

## Project Overview
Our project is an AI-powered platform that detects fake news across multiple Indian languages. Users can input text or upload screenshots to analyze the credibility of a claim. The system uses NLP and AI techniques to detect misinformation patterns, cross-checks claims with verified sources, and provides a credibility score with clear explanations. It also includes advanced features like propagation tracking, a fake news library, and an awareness guide to promote informed decision-making.

---

## Features
- **Multilingual Fake News Detection** – Supports multiple Indian languages with translation  
- **AI Claim Autopsy** – Highlights misleading phrases and manipulation techniques  
- **Truth Engine** – Provides verified alternatives and factual explanations  
- **Fake News Probability Score** – Clear percentage with reasoning  
- **Propagation Tracker** – Visualizes how misinformation spreads across platforms  
- **Screenshot Analysis** – Upload images and extract text using OCR  
- **Fake News Library** – Collection of widely shared debunked claims  
- **Awareness Guide** – Educates users on identifying misinformation

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js  
- **AI/NLP:** Groq API, TF-IDF, heuristic models  
- **APIs:** Google Fact Check API, News APIs  
- **Data:** Verified claims dataset (JSON)  

---

## Architecture / Workflow
1. User enters text, link, or uploads an image  
2. System detects language and preprocesses input  
3. AI model analyzes content using NLP and Groq API  
4. Claims are verified using fact-checking APIs  
5. Heuristic engine detects patterns and virality signals  
6. System generates credibility score with explanation  
7. Optional modules show propagation and truth insights
